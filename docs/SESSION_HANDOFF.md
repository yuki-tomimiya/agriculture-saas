## 2. プロダクトの芯（変えない前提）

- **サービス名**: **Tillto**（決定済み。`agriculture-saas` は npm 内部名のみ）
- **一言**: 教科書の一般論 × この地域のリアル × あなたの農場の履歴 → **今日の一手**
- **3層**: 【あなた】【地域】【一般】→ 結論（今日の一手）。表示ラベル統一
- **時間軸**: 過去（記録）→ 現在（把握）→ 未来（提案）

詳細は議事録 ›「プロダクト趣旨・ポジション」。

## 6. 画面・ルート早見（現状）

```
/dashboard/ai-proposal   今日の一手（3層）
/gdd                   生育ナビ・栽培中のみ
/gdd/past              過去作付け一覧 → /gdd?cropId=… でグラフ
/insights              分析（比較+地域+一般が1枚に同居 ← 要入口化）
/calendar              作業カレンダー（昨年オーバーレイ）
/weather               気象ナビ
```

サイドバー: AI提案(紫) → ダッシュボード → カレンダー → 気象 → 生育ナビ → 農場/作物/作業/農薬/収穫/販売 → **分析・振り返り** → タスク → 外部連携 → FAQ
